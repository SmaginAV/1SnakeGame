# Первая публикация 1SnakeGame на GitHub

Комплект подготовлен для первой публикации `v1.0.0`. Используйте обновлённый архив `1SnakeGame-GitHub.zip`: в нём находятся готовая обработка, исходники и README с новым скриншотом игры с закруглёнными сочленениями прицепа.

## 1. Подготовьте каталог

Распакуйте архив в новый пустой каталог. Внутри находится папка `1SnakeGame` с такой структурой:

```text
1SnakeGame/
  README.md
  PUBLISHING.md
  1SnakeGame.epf
  ИграЗмейка.xml
  ИграЗмейка/
    Forms/...
    Templates/...
  assets/
    gameplay.png
  .gitignore
  SHA256SUMS.txt
```

В корень будущего репозитория загружается содержимое этой папки. Сохраните `assets/gameplay.png` по указанному пути: на него ссылается README. Файлы `Template.bin` нужны для сборки обработки из исходников.

В пакете ссылка на EPF в README уже адаптирована к корню репозитория. Файл лицензии автоматически не добавлялся; при необходимости добавьте выбранную вами лицензию.

## 2. Создайте репозиторий

На GitHub выберите **New repository**, укажите имя `1SnakeGame` и видимость **Public** для общедоступной страницы. Оставьте добавление README, `.gitignore` и лицензии при создании выключенным: файлы проекта будут загружены следующим шагом. Завершите создание кнопкой **Create repository**. [Официальная инструкция GitHub](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository).

Готовое описание репозитория:

```text
Змейка на колёсах на чистом 1С: внешняя обработка, табличный документ, управление с клавиатуры и общий топ-10 рекордов. Без БСП.
```

Подходящие темы проекта: `1c`, `bsl`, `snake-game`, `epf`, `game`.

## 3. Загрузите файлы

На странице пустого репозитория откройте ссылку **uploading an existing file**; если список файлов уже отображается, используйте **Add file → Upload files**. Перетащите содержимое распакованной папки `1SnakeGame`, включая `assets/`, `ИграЗмейка/` и `.gitignore`, и сохраните изменение с сообщением `Добавлена игра 1SnakeGame`. В результате README должен оказаться в корне репозитория. [Загрузка файлов на GitHub](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).

После загрузки проверьте: на главной странице виден README, в нём отображается новый скриншот с закруглёнными поворотами прицепа, ссылка на `1SnakeGame.epf` открывает файл.

Вместо загрузки через браузер можно использовать Git. Выполните команды **в распакованной папке `1SnakeGame`**, заменив `YOUR_LOGIN` на владельца созданного пустого репозитория:

```powershell
git init
git add .
git commit -m "Добавлена игра 1SnakeGame"
git branch -M main
git remote add origin https://github.com/YOUR_LOGIN/1SnakeGame.git
git push -u origin main
```

## 4. Добавьте готовый EPF в релиз

В репозитории откройте **Releases → Draft a new release**. Создайте тег `v1.0.0`, выберите ветку с загруженными файлами (обычно `main`) и укажите заголовок `1SnakeGame 1.0.0`. Приложите файл `1SnakeGame.epf` из распакованного пакета, чтобы пользователи могли скачать обработку отдельно от исходников. [Создание релиза на GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository).

Текст для описания релиза:

```markdown
Первая публикация 1SnakeGame — змейки на колёсах, написанной на чистом 1С.

- Тягач с полуприцепом и растущий сплошной зелёный прицеп с закруглёнными сочленениями на поворотах.
- Игра в табличном документе, управление стрелками, выход в меню по Esc.
- Светло-серый интерфейс и встроенные картинки.
- За яблоко начисляется 10 очков; цифра «5» на нём декоративная.
- Общая таблица топ-10 результатов текущей информационной базы.
- Без БСП и установки объектов в конфигурацию.

Требуется платформа 1С:Предприятие 8.3.27+, управляемые формы тонкого или толстого клиента. Проверено на 8.3.27.2074.

Скачайте 1SnakeGame.epf и откройте файл в 1С. Сохранение рекордов зависит от прав платформы; известное ограничение ограниченного профиля описано в README.
```

Проверьте вложенный EPF и описание, затем выберите **Publish release**; для сохранения неподготовленного релиза используйте **Save draft**. После публикации можно разместить ссылку на релиз в описании репозитория.

## Проверка файла

Хеши файлов пакета записаны в `SHA256SUMS.txt`. Хеш отдельной обработки можно проверить командой:

```powershell
Get-FileHash -LiteralPath .\1SnakeGame.epf -Algorithm SHA256
```
